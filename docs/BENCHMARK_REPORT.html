Natural code-switched ASR

We selected 100 hash-frozen AfriSwitch clips per language, balanced across code-mixing, switch count, duration, and source groups. Every model received identical 16 kHz PCM16 audio. Sahara code-switched TTS

One hundred genuine code-switched AfriSwitch texts, 25 per language, were synthesized once with female and male Sahara voices. All outputs were valid 22.05 kHz mono PCM16 WAVs, totaling 1,672.29 seconds with no clipped samples. Three independent ASR families judged every output.

Failure analysis

All 27 strict failures came from nine stable scenario/provider cells where ASR lost a symptom or language cue. No run leaked declared PII or promoted an unconfirmed incident as fact.

Metrics, reproducibility, and limits

Metric definitions

  • WER = substitutions + deletions + insertions, divided by reference words. Lower is better and values may exceed 100%.
  • Hallucination / transcript loss use insertion and deletion rates as automatic TTS indicators.
  • Segment loss is the share of tagged language spans with no correctly aligned word.
  • Strict task success requires every analysis, tool-trace, response, state, and privacy assertion to pass.
  • pass@1 / pass@3 / pass³ mean first-run, any-of-three, and all-three success.
  • Capability retention divides ASR-transcript task success by gold-transcript success.

Reproducible evidence

  • Frozen manifests bind every sample and generated WAV to SHA-256.
  • Raw JSONL is append-only and retains failures, provider IDs, parameters, model versions, code commit, lock hash, and latency.
  • `make benchmark-verify-asr-evidence`, `-tts-evidence`, and `-agent-evidence` regenerate public aggregates byte for byte.
  • Private ASR evidence: Tiamz/faultbridge-asr-benchmark-evidence, revision ef320d7f…fe00.

Measured routing decision

Use Sahara for all four language pairs in the submission. No alternative currently combines a statistically supported paired WER advantage, ≤1% provider-failure evidence, comparable deployed p95 latency, and zero critical downstream failures. The evidence-gated router is implemented, but multi-ASR routing stays off until those conditions pass.

Responsible deployment boundary

Consent and privacy. Declined consent bypasses speech and model providers. Accepted transcripts are redacted before the LLM, database, tools, logs, or UI; caller IDs are HMAC-pseudonymized.

Grounding. Verified incidents and account records enter through authenticated internal APIs. Missing values stay unknown.

Agent authority. The LLM extracts a constrained complaint schema. Deterministic policy authorizes typed tools, and every tool input/output is audited.

Crowd discovery. Three distinct callers may create an unconfirmed candidate incident; only an operator can verify it.

Limitations

The natural ASR panel is difficult research speech, not a population prevalence sample. The named-ASR panel uses one Sahara female synthetic voice and may favor Sahara recognition. Automatic TTS judges cannot replace bilingual listening. The privacy claim excludes names, street addresses, and fully word-spelled numbers. API, CPU, and GPU timing environments are not directly comparable. FaultBridge still requires authoritative NOC/CRM integrations, a telco security review, matched live-stream latency, and human call trials before production.
